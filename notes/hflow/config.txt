# /etc/config.txt on the SD card -- sourced by rcS on every boot (rcS line ~314),
# after the param file is loaded and before sensors / uavcan / ekf2 start, so
# reboot_required params below apply on this same boot.
#
# Install:  copy this file to the SD card as  etc/config.txt  (make the etc folder).
# Verify:   the boot log (QGC MAVLink Console, `dmesg`) prints "Custom: /fs/microsd/etc/config.txt".
# Note:     these lines re-apply every boot and will override any later change made in QGC.
#           Remove a line here if you want to tune that param from QGC instead.
#
# Same values as hflow.params. Keep the two files in sync.
